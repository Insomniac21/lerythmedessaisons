# Le Rythme des Saisons

Site statique d’une page pour la fermette familiale **Le Rythme des Saisons**, près de Saint-Jean-sur-Richelieu (Québec).

On y présente les cailles japonaises et les cochons d’Inde, la chaîne YouTube et les produits de saison (œufs de caille frais, sur réservation).

Le site est publié avec GitHub Pages, branche `main`, dossier `/`, sur le domaine [lerythmedessaisons.ca](https://lerythmedessaisons.ca).

## Fichiers

- `index.html` — la page
- `styles.css` — la mise en page
- `assets/` — images et icônes
- `favicon.ico` — icône du site
- `CNAME` — domaine personnalisé
- `.nojekyll` — publication sans traitement Jekyll
